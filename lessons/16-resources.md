- Lighthouse and DevTools documentation

## Tools and utilities
- VS Code + Live Server extension
- Browser DevTools (Elements, Network, Lighthouse)
- Image optimizers: Squoosh, ImageOptim
- Git & GitHub for version control and deployment

## Suggested learning path after this course
1. Deepen CSS: animations, advanced selectors, preprocessors (Sass).
2. Learn JavaScript frameworks (React/Vue) after mastering DOM.
3. Server basics: Node.js and simple backends for forms.
4. Accessibility specialization and performance engineering.

## Final tips for students
- Build, iterate, and deploy small projects regularly.
- Read other people's code and participate in reviews.
- Keep accessibility and performance in your checklist for every release.
