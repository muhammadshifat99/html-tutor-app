# Lesson 15 — Assessments and Quizzes

Duration: Flexible
Level: All levels

## Goals
- Verify student understanding through small quizzes, practical tasks, and a capstone project.

## Assessment types
- Short quizzes (multiple choice) for key concepts.
- Practical tasks: small coding exercises (fix HTML, add semantic tags, style a component).
- Project rubric: evaluate portfolio projects using a checklist.

## Example quiz questions
1. What is the correct HTML element for the largest heading? (`<h1>`)
2. Which attribute provides an accessible name for an abbreviation? (`title`)
3. True/False: Use tables for layout. (False)

## Practical exercises
- Clean up a provided `index-broken.html` file and make it semantic and accessible.
- Build a responsive navigation bar using Flexbox.

## Grading rubric (suggested)
- Semantics & accessibility: 30%
- Responsiveness & layout: 25%
- Code quality & comments: 15%
- Functionality & interactivity: 20%
- Presentation & README: 10%
