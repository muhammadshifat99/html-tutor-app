# Lesson 14 — Projects and Portfolio

Duration: Flexible (project-based)
Level: Advanced (capstone)

## Learning objectives
- Apply learned HTML/CSS/JS skills to build real projects.
- Structure a portfolio site to showcase projects and explain decisions.
- Use version control (git) and deploy to static hosts (GitHub Pages, Netlify).

## Project ideas
- Personal portfolio site (bio, projects, contact form).
- Small e‑commerce product list with sorting/filtering (frontend only).
- Accessible blog template with article templates and comments (static).
- Interactive TODO app persisted in `localStorage`.

## Outline
1. Project requirements and rubric (15 min)
   - Define success criteria: semantic HTML, responsive layout, accessibility, deployable.

2. Work plan (in-class)
   - Break project into pages/components, wireframe, and milestone plan.

3. Deployment (30 min)
   - Intro to GitHub Pages: push repo and enable pages; Netlify quick deploy.

4. Review and critique (ongoing)
   - Peer review sessions and checklist-based grading.

## Teacher notes
- Provide starter templates and a checklist covering semantics, accessibility, responsiveness, SEO, and performance.
- Encourage writing short project READMEs describing technologies and design choices.
